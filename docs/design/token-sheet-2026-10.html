Motion §2

Three durations × three easings. Each dot travels for exactly its token's duration, then holds. Spring is shown for completeness. It is allowed on switch knobs only.

Your OS has reduce motion on, so animations are paused here, as the product does via its global kill switch (§2.3).

--ease-out-soft (default)
--ease-in-out-soft (exits, loops)
--ease-spring (knobs only)
--motion-fast120ms · hover, reveal, exits, tooltips
--motion-base180ms · menus in, toggles, values
--motion-slow240ms · dialogs, drawers, slides

drag + drop

Drop indicators track the pointer with no transition; the drag source dims instantly to 0.4; nothing settles after drop. Attention signals (locate flash 1.2s, anchor flash 1.8s, flow pulse 0.7s, cursor-label dwell 2.8s, skeleton 1.6s) are timers, so the scale does not apply to them. They still use an --ease-* token.

Radius §3

Assigned by surface role, not nearest number. Nesting is concentric: inner = outer − padding, never below sm.

none · 0table cells, dividers, rail side of quotes
sm · 4pxinline marks, menu items, selection wash, marquee, grips
md · 6pxstandalone controls: gutter + toolbar buttons, inputs, tooltips
lg · 8pxblock surfaces + floating menus (4 item + 4 pad)
xl · 12px newdialogs, command palette, lightbox, slides
pill · 9999pxchips, switches, progress, lamps (50% for circles)

Editor palette vs data palette §7

Editor palette = authored emphasis stored in the document (text, highlight, block bg, callouts, syntax hues). Data palette = encodes data (chips, series, status) and follows the viewer's scheme. Never cross. Meters and controls use --primary.

Block chrome §8

The gutter is positioned by one formula, top = lead-offset + (lead-line − 24px) / 2, using variables each family declares from its own tokens. No per-type tuning. The dashed tick marks where each gutter is centred. Hover the gutter buttons for live states.
